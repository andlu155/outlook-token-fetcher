🌐 网络代理
勾选并保存后，本扩展会设置 Chrome 系统代理，登录/注册流量会走该代理。仅填写地址不勾选 = 不生效。普通窗口保存会同时写入普通 + 无痕；取消勾选再保存则恢复系统代理。

使用上方填写的代理临时测一次（不必先保存），测完自动恢复原设置。主探测站 Cloudflare（cdn-cgi/trace），失败时回退 ipify / Microsoft；成功后查询出口 IP 真实地区。无痕窗口内测试会写入无痕会话代理。
